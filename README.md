# Daily Finance Pro v3.1 — hosting pack

ఈ ఫోల్డర్ = మీ యాప్ (ఒకే ఫైల్ `index.html`) + ఇన్‌స్టాల్ ఫైల్స్. దీన్ని GitHub Pages లేదా Vercel లో పెడితే కస్టమర్ పాస్‌బుక్ లింక్‌లు నిజమైన వెబ్‌సైట్ అడ్రస్‌తో పనిచేస్తాయి.

| ఫైల్ | పని |
|---|---|
| `index.html` | యాప్ మొత్తం (మీ Firebase config లోపలే ఉంది — లాగిన్ పేజీ నేరుగా పనిచేస్తుంది) |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | ఏజెంట్ యాప్ ఇన్‌స్టాల్ (💰 ఐకాన్) |
| `customer.webmanifest`, `icon-pb-*.png` | కస్టమర్ "Passbook" యాప్ ఇన్‌స్టాల్ (📖 ఐకాన్) |
| `sw.js` | ఆఫ్‌లైన్ + ఆటో-అప్‌డేట్ |
| `firebase-rules.json` | Firebase → Realtime Database → Rules లో పేస్ట్ చేసేది (యాప్‌లోని "📋 Copy Firebase rules" బటన్ మీ ఖాతాకే లాక్ చేసిన వెర్షన్ ఇస్తుంది — అదే మంచిది) |
| `vercel.json` | Vercel సెక్యూరిటీ హెడర్లు (GitHub Pages కి అవసరం లేదు) |

## v3.1 లో కొత్తవి
- 🔐 **లాగిన్:** మొబైల్ నంబర్ (లేదా Gmail) + 6 అంకెల PIN. కొత్త ఫోన్ / డేటా క్లియర్ అయినా లాగిన్ చేస్తే డేటా మొత్తం తిరిగి వస్తుంది.
- ☁️ **ఆటో బ్యాకప్:** ప్రతి మార్పు కొన్ని సెకన్లలో మీ Firebase లో (`bk/` కింద) సేవ్ అవుతుంది. మాన్యువల్ బ్యాకప్ అక్కర్లేదు (ఐచ్ఛికంగా సెట్టింగ్స్ లోపల ఉంది).
- 📲 **కస్టమర్ యాప్:** కస్టమర్ పాస్‌బుక్ లింక్ తెరిస్తే "Install passbook app" — హోమ్ స్క్రీన్‌పై 📖 Passbook ఐకాన్, నేరుగా లైవ్ పాస్‌బుక్.
- 📅 షెడ్యూల్‌లో ప్రతి రోజుకీ అమౌంట్; ఈరోజు వాయిదా = "ఈరోజు కట్టాల్సినది" (బాకీ కాదు).

## ⚠️ ఒక్కసారి చేయాల్సింది
కొత్త rules లో `bk` (బ్యాకప్), `dir` (మొబైల్ → Gmail) భాగాలు ఉన్నాయి. యాప్ → సెట్టింగ్స్ → **📋 Copy Firebase rules** → Firebase → Realtime Database → Rules → పాతది తీసేసి పేస్ట్ → **Publish**.

**ముఖ్యం:** రిపోజిటరీ *పబ్లిక్* అయితే యాప్ కోడ్ మాత్రమే పబ్లిక్ — కస్టమర్ డేటా ఇందులో ఉండదు. Firebase web config (apiKey) పబ్లిక్‌గా ఉండేదే; భద్రత rules లో ఉంటుంది. బ్యాకప్ ఫైల్స్ / CSV ఎప్పుడూ అప్‌లోడ్ చేయవద్దు.

అప్‌డేట్ చేయాలంటే: కొత్త ఫైల్స్‌ను అదే పేర్లతో రిపోజిటరీలో replace చేయండి — ఫోన్‌లు తదుపరిసారి తెరిచినప్పుడు ఆటోమేటిక్‌గా కొత్త వెర్షన్ వస్తుంది.
