# Daily Finance Pro — hosting pack

ఈ ఫోల్డర్ = మీ యాప్ (ఒకే ఫైల్ `index.html`) + ఇన్‌స్టాల్ ఫైల్స్. దీన్ని GitHub Pages లేదా Vercel లో పెడితే కస్టమర్ పాస్‌బుక్ లింక్‌లు నిజమైన వెబ్‌సైట్ అడ్రస్‌తో పనిచేస్తాయి.

| ఫైల్ | పని |
|---|---|
| `index.html` | యాప్ మొత్తం |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | ఫోన్ హోమ్ స్క్రీన్‌లో ఇన్‌స్టాల్ + ఆఫ్‌లైన్ + ఆటో-అప్‌డేట్ |
| `firebase-rules.json` | Firebase Realtime Database → Rules లో పేస్ట్ చేసేది (లైవ్ సింక్ కోసం) |
| `vercel.json` | Vercel సెక్యూరిటీ హెడర్లు (GitHub Pages కి అవసరం లేదు) |

**ముఖ్యం:** ఈ రిపోజిటరీ *పబ్లిక్* అయితే యాప్ కోడ్ మాత్రమే పబ్లిక్ — కస్టమర్ డేటా ఇందులో ఉండదు (అది మీ ఫోన్‌లోనే ఉంటుంది). బ్యాకప్ ఫైల్స్ / CSV ఎప్పుడూ అప్‌లోడ్ చేయవద్దు.

అప్‌డేట్ చేయాలంటే: కొత్త `index.html` ను అదే పేరుతో రిపోజిటరీలో replace చేయండి — ఫోన్‌లు తదుపరిసారి తెరిచినప్పుడు ఆటోమేటిక్‌గా కొత్త వెర్షన్ వస్తుంది.
